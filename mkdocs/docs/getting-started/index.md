**Harmony Engine** is particularly well-suited for developers who:

- Want to use a completely free and open-source game engine (MIT)
- Are building any game in the 2d genre
- Want a code-first workflow without the overhead of large general-purpose engines. 
- Need builds that are performant, lightweight, and cross-platform (PC and web browser - WASM)

!!! info "Harmony is built with and uses C++"
    Basic C++ knowledge including classes, pointers and lambdas is recommended, but Harmony can be a great introduction to C/C++ for those wanting to learn as a major annoyance of making builds is eliminated by HyEditor.

<div align="center">
<h3>The Harmony Engine consists of two main projects.</h3>
</div>

**HyEditor** - The editor tool that manages projects & builds, assets, and creates prefabs to assemble entities/scenes.

**HyEngine** - The runtime static library that links into your game application. It provides the API to the engine features, and classes to instanciate instances of the prefabs and entities created in HyEditor.
